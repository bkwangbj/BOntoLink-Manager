快速上手

十分钟建出第一个能用的对象类型。这套系统管的是元数据——你定义「有哪些实体、实体有哪些字段、字段什么含义、实体之间怎么连」，上层的报表、问答、探索都读这层定义去取数。

  1. 先选好落点。进 系统配置 → 行业分类，确认你要建的东西属于哪个「行业 → 领域」。没有就先建一个领域，并给它绑命名空间。
  2. 进 资源 → 对象类型，左侧分类树点中刚才那个领域，点右上角 新建，走创建向导：填编码、显示名、api_name、图标和颜色。
  3. 右侧抽屉切到 属性 页签，逐条加字段。取值有约束的挂值类型，取值是固定几项的先去建枚举类型再经值类型引用。
  4. 字段是全系统通用的（行政区划代码、统一社会信用代码之类），别在这里重复定义——去 共享属性 建一次，各处引用。
  5. 要连到别的实体，进 资源 → 链接 建一条链接类型：选两端对象、定基数、配字段映射。
  6. 要落到真实数据上，进 数据源 建连接 → 同步物理表 → 回对象类型的「数据源」页签做表与列的映射。
  7. 建完去 工作区 → 实例探索 打开它，看能不能正常出数、筛选、出图。能在探索里查出来，才算建成了。
不确定某个功能长什么样，就去总览页点对应的统计卡片跳过去，系统里已经有一批演示数据（48 个对象类型、9 个动作、44 个类型类…），照着现成的看比从空白开始快得多。

概念地图

名词有点多，但它们的关系其实是一条线。先看懂这张图，后面每一章都好读。

依赖方向

层是什么被谁用
行业分类 / 命名空间所有资源的归属与筛选维度，三层：行业 → 领域 → 分组全部模块的左侧过滤树
枚举类型有限取值的字典，可多级、可从外部库同步值类型的 Enum 约束
值类型取值的语义包装：基础类型 + 一条约束对象属性 / 共享属性 / 接口属性
共享属性跨对象复用的属性定义对象类型的属性、结构属性
对象类型本体的核心实体链接、动作、接口实现、实例探索
链接类型两个对象之间的关系，带基数与双向命名图谱、跨对象取数
动作类型挂在对象上的可执行操作上层业务入口
接口纯抽象契约，一组属性约定对象类型去「实现」它
类型类给属性/关系/动作挂的元数据标签 + 参数图表、图谱等上层渲染
数据源物理库连接 / 外部 HTTP 接口对象类型的物理表映射、枚举同步

一句话区分几组容易混的

  • 枚举类型 vs 字典管理：枚举类型是业务字典（水质等级、工程等别），参与本体建模、可被值类型引用、可从外部库同步；字典管理是系统字典（下拉选项、状态码），只服务于界面回显。
  • 值类型 vs 数据类型：数据类型是 XSD 层面的 string/int/date；值类型在它之上加一条语义约束（长度、正则、必须是 RID、必须来自某枚举）。
  • 共享属性 vs 结构属性：共享属性是一个字段；结构属性是一组共享属性打成的包（如「联系方式」= 姓名 + 电话 + 邮箱）。
  • 接口 vs 类型类：接口约束「你必须有这些属性」；类型类是「给这个属性/关系贴个标签并带参数」，供上层解释怎么渲染。
  • 链接类型 vs 对象属性(object 类)：链接是双向的、有基数、可落到中间表的一等公民；对象属性只是把某个字段声明为指向另一个类。要在图谱里画出来、要能跨对象取数，用链接。

能做与不能做

先说清边界，省得在系统里找一个根本不存在的功能。

① 系统里没有真实的业务数据

本产品管的是元数据——「水库这个实体有哪些字段」。至于「张三水库库容 3200 万方」这条记录，权威副本在你的业务库里。

实例探索里看到的那些数据是模拟生成的：按对象类型的属性定义确定性地造出来，用于验证「这个模型建得能不能用、筛选和聚合是否符合预期」。种子固定，重启后完全一致。所以：

  • 可以：在探索里验证列、筛选、聚合、关联跳转是否符合预期。
  • 不可以：把它当业务数据看，或在里面新增/修改/删除记录。

② 动作的「执行」是模拟执行

试运行会算出「将写入的实例记录」和「将触发的副作用」，并落一条执行记录，但不写任何物理表。它的用途是验证规则顺序、值来源解析、必填校验是否配对了。

③ 没有权限体系

「权限安全」页是占位的。当前所有人看到的功能一样，任何人都能改任何东西。多人协作时靠约定，不靠系统。

④ 几个还没上线的模块

模块现状影响到什么
函数占位页动作里的「运行函数」规则可以配，但选函数的按钮是占位；对象类型的「函数」页签为空
导入导出占位页跨环境迁移目前只能靠数据库层面的备份还原
AI 助手占位对话页回复是固定话术，没接推理引擎
权限安全静态表格见上

⑤ 几条容易踩的相互作用

  • api_name 建完不能改。对象类型、接口、值类型都是这样。改了会打断下游所有引用，所以界面上直接锁死。想改只能删了重建——而被引用的又删不掉。建之前把编码想好。
  • 被引用的东西删不掉。共享属性 ref_count>0、对象类型有属性/链接/动作引用、受系统保护的类型类，删除都会被拒绝并列出引用清单。这是有意的。
  • 值类型的基础类型保存后不能改。约束可以改，基础类型不行——因为已经有属性按这个类型落地了。
  • 改了共享属性，不会回写到已经引用它的对象属性上。共享属性是「引用」不是「继承」。要统一口径，就在建模时引用它，而不是指望事后同步。

行业分类与命名空间 建模前置

系统配置 → 行业分类。这是全系统的归属与筛选维度，其它模块的左侧过滤树都读它。建任何资源之前，先确认落点存在。

三层结构

行业 → 领域 → 分组。行业是最粗的一层（水利、交通、应急…），领域是行业下的业务细分（水文、水资源、水土保持…），分组是领域内按主题把对象类型归到一起。

  • 命名空间挂在领域上：ns_code、URI、当前版本、层次路径。领域是本体术语的作用域，所以命名空间绑在这一层。
  • 分组有成员：进分组节点的「成员」页签，把对象类型加进来，可以拖拽排序。
  • 节点的图标和颜色在「显示」页签选，会带到各处的列表和卡片上。

左栏 / 中栏 / 右栏各管什么

区域内容
左：树树 / 列表双视图，展开折叠 + 统计徽标 + 右键菜单。领域节点下挂版本列表。悬停有快速添加菜单
中：概览或详情没选中节点时是全局概览（统计卡片 + 行业柱状图 + 行业卡片）；选中后是面包屑 + 统计 + 子节点网格 + 关联图
右：详情抽屉页签随节点类型变：行业/领域有「基础信息 / 命名空间 / 显示 / 其他」，分组有「基础信息 / 成员 / 显示 / 其他」
搜索框支持中文、拼音、拼音首字母三种输入。分类多了以后打 shuiwen 或 sw 比翻树快。
删除节点前系统会做级联校验：有下级节点、或有资源挂在它下面，都会拒绝并告诉你卡在哪。想删就先把下面的东西挪走。

对象类型 核心

资源 → 对象类型。一个对象类型 = 类定义 + 属性集 + 关系 + 约束 + 物理映射 + 业务应用。抽屉里 4 组 15 个页签，按颜色分组。

新建：走向导

点新建走分步向导，一次把「类 + 数据源 + 属性字段映射」建齐（后端是一个事务，中途失败不会留半截数据）。向导里填的东西：

  • 编码 / 显示名 / api_name —— api_name 建完锁死，见 编码与命名。
  • 所属分类 —— 决定它出现在哪个领域下。
  • 图标 + 颜色 —— 会带到列表、卡片、图谱、探索的所有地方，选一个有辨识度的。

抽屉支持二级嵌套：在链接关系图里点开一条链接，会再叠一层抽屉出来编辑，最多叠 8 层，逐层关闭。

绑物理表

  1. 前置：数据源已建好并同步过物理表（见 数据源）。
  2. 抽屉切「数据源」页签，选数据源和表，指定它是主表还是附表。
  3. 回「属性」页签，逐个属性填物理表名与列名。
解绑数据源会级联清空该绑定下所有属性的字段映射。改绑之前先确认映射关系有备份或能重建。

属性怎么配

属性是建模里最费工夫的地方。这一节把一行属性上的每个格子说清楚。

三种属性种类

prop_type含义典型例子
data 数据属性取值是字面量测站名称、库容、建站年份
object 对象属性取值指向另一个类的实例，需填「值域类」所属河流
annotation 注解属性只做说明，不参与推理备注、来源说明
要在图谱里画成一条边、要能跨对象取数，用 链接类型 而不是 object 属性。object 属性只是声明「这个字段指向那个类」。

一行属性上的格子

  • 编码 / 显示名 —— 编码是机器用的，显示名是人看的。
  • 数据类型 —— XSD 类型（string / integer / decimal / boolean / dateTime…）。
  • 值类型 —— 可选。挂上之后这个属性就带上了语义约束，见 值类型。
  • 主键 / 必填 / 派生 / 多值 —— 四个开关。派生表示它是算出来的，不直接存。
  • 父属性 —— 属性的层次关系（rdfs:subPropertyOf）。
  • 排序 —— 直接拖行调整，影响所有展示这些属性的地方的顺序。

OWL 特性与 XSD 约束

展开一条属性还能配 7 个 OWL 特性（函数性、反函数性、传递性、对称性、反对称性、自反性、非自反性）与 6 个 XSD 约束（长度、上下限、小数位…）。这些是给推理引擎和校验用的，不影响界面展示。

属性格式化

点属性行上的格式化入口，配置这个属性在各处怎么显示（小数位、单位、前后缀、日期格式）。接口属性支持批量格式化：多选后一次设同一套规则。

链接 关系建模

资源 → 链接。编辑器是上下对称的双栏：上面源端，下面目标端，两边字段一模一样。这个布局是有意的——关系本来就是对称的，正反两个方向都要起名字。

两端各要填什么

字段说明
对象类型这一端是哪个类
基数one / many。两端组合出 1:1 / 1:N / N:1 / N:N
显示名从这一端看过去，这条关系叫什么。比如源端叫「所属河流」，目标端叫「下辖测站」
复数名基数是 many 时启用，用于「下辖测站们」这种复数表述
api_namecamelCase
可见性normal 普通 / prominent 突出 / hidden 隐藏
启用开关单端可以关掉，只保留一个方向

关系落到数据上：两种方式

方式一：字段映射（默认）

两端各出一个字段对上，等价于外键。复合主键就多加几行，按序号排列。

方式二：中间表

打开「数据源关系」开关，填中间表物理表名。这时每行映射除了对象属性名，还要填中间表列名。N:N 关系通常走这种。

状态

三态：experimental 实验 → active 正式 → deprecated 废弃。列表可以按状态和基数筛选。

建完在对象类型详情的「链接关系」页签核对一下画出来的方向和基数对不对——那个画布用的是同一个编辑器，可以直接在图上改。
保存时 mappings 是整体覆盖（先删后插），不会留孤儿行。所以编辑时要把所有映射行都留在表里，不能只提交改动的那几行。

动作类型 可执行 模拟执行

资源 → 动作类型。动作是本体从「描述」走向「可操作」的部分：一个动作 = 一张表单（收集输入）+ 一组有序规则（做什么）+ 一套提交标准（什么条件下允许提交）。

新建：五步向导

点新建走五步向导，确定主体对象类型、编码、名称与基本配置。建完进详情工作台细配。

详情工作台：三栏

  • 左导航：概览 / 表单 / 规则 / 安全与提交。表单和规则可以展开成下级树，直接点到某个参数或某条规则。
  • 中内容区：当前选中项的完整编辑页。
  • 右预览：表单实时预览——你配的是下拉还是单选、必填标记在哪，这里立刻看到。

表单页

  1. 按分区组织参数（如「基础信息」「位置与状态」）。分区名点一下可以重命名，也可以删。
  2. 每个分区独立的「添加参数到本分区」按钮。参数行 hover 出现拖拽手柄，可以跨分区拖。
  3. 点参数进详情，四个标签：值 / 显示 / 覆盖 / 详情。标签是粘性锚点，滚动会联动高亮。

参数的「值」标签

数据类型有 string / number / boolean / object / enum 五种，选了类型之后显示类型（输入框 / 下拉 / 单选 / 多选 / 日期…）会自适应给出合理选项。

对象引用参数和字符串多选参数可以配「从对象集获取」：

  • 起始对象集 —— 从「全部对象」里挑一个对象类型，或引用表单里已有的对象参数作为变量。
  • 按属性过滤 —— 属性 + 运算符 + 比较值，一行一条。
  • 关联搜索 —— 选一个链接类型，自动生成「关联搜索至 X 的 Y」，顺着关系跳到对端对象。
  • 字符串多选形态末尾还有返回属性（取对象的哪个字段当选项值）。

规则页

规则是有序的折叠卡片，从上到下依次生效，可以拖拽排序，每条可以单独启停。八种规则：

类别规则
本体编辑类创建对象 / 修改对象 / 删除对象 / 创建链接 / 删除链接 / 运行函数
副作用类通知 / Webhook

属性映射：值从哪来

每条本体编辑类规则的核心是一张属性映射表：目标属性 ← 值来源。四类来源：

  1. 来自参数 —— 取表单里某个参数的值。
  2. 对象参数属性 —— 两级级联：先选一个对象类参数，再选它的某个属性。
  3. 静态值 —— 写死。
  4. 当前用户 / 系统时间 —— 自动填充。

「取值配置」这一格会随所选来源自动换成对应的控件（下拉 / 文本框 / 自动）。

四类规则的完整编辑页

  • 函数规则：绑定函数 + 版本 + 自动升级开关 + 代码预览 + 入参映射弹窗（类型不匹配会标红）+ 执行配置 + 异常映射。
  • 通知规则：收件人配置、内容配置（描述 / 函数双 tab）、多选渠道（推送 / 邮件 / 短信）、链接配置、高级配置。
  • Webhook 规则：类型卡（回写 / 副作用）、选 Webhook + 版本、输入参数表、执行说明。
  • 对象 / 链接规则：目标对象参数选择器 + 对象类型 + 主键属性 + 属性映射表（「修改对象」才有操作符列）+ 关联链接配置。

规则冲突

系统会拦三类无效组合，能在入口拦的直接禁用卡片，拦不住的在顶部出红条并阻止保存：

  • 重复创建（已经有一条启用的「创建对象」规则）
  • 删除之后又修改
  • 副作用排在本体编辑之前

安全与提交

提交标准是一棵嵌套条件树：all（全部满足）和 any（满足其一）可以互相嵌套，配出「A 且 (B 或 C)」这类判断。

试运行

管理页操作列的 ▶ 按钮打开试运行弹窗。填参数后系统会：校验必填 → 解析各条规则的值来源 → 算出「将写入的实例记录」和「将触发的副作用」 → 落一条执行记录。

试运行不写任何物理表。它验证的是「规则配对了没有」，不是「数据落进去没有」。执行历史在动作详情里可查。

状态

0 草稿 → 1 已发布 → 2 已停用。配置期间留在草稿，试运行确认无误再发布。

共享属性 / 结构属性

资源 → 共享属性。双 Tab：普通属性 / 结构属性。凡是会在多个对象类型上重复出现的字段，都应该先在这里定义一次。

共享属性

新建走三步向导（元数据 → 配置 → 保存位置）。详情抽屉五个页签：基础信息 / OWL 特性 / 约束 / 引用 / 注释，默认只读，点一下切编辑态。

  • prop_code 唯一且建完不可改。
  • 携带 7 个 OWL 特性、6 个 XSD 约束、4 个 RDFS 语义字段。
  • 「引用」页签列出哪些对象类型属性用了它——删之前先看这里。
ref_count > 0 的共享属性删不掉；批量删除会自动跳过被引用的那些，只删干净的。
改共享属性不会回写到已经引用它的对象属性上。共享属性是「引用」不是「继承」——要统一口径就在建模时引用它，别指望事后同步。

结构属性

把若干共享属性打成一个包。左右双栏：左边结构列表，右边这个结构的条目表，条目可以拖拽重排。

典型用法：「联系方式」= 姓名 + 电话 + 邮箱，三个共享属性组成一个结构，之后哪个对象需要联系方式就整包引用。

值类型

资源 → 值类型。给属性的取值加一层语义包装：基础类型 + 一条约束。三个页签：元数据 / 约束配置 / 预览验证。

五种基础类型 × 五种约束

约束配什么什么时候用
RID资源标识符格式字段存的是本系统资源的 ID
UUID—字段是 UUID
Length长度上下限名称、编码这类有长度要求的
Regex正则表达式身份证、手机号、行政区划码
Enum绑定一个枚举类型 + 使用配置取值来自固定字典

基础类型五种：String / Integer / Decimal / Boolean / DateTime。api_name 和基础类型保存后都不能改，约束可以改。

Enum 约束的使用配置

枚举是多级的时候，还要决定怎么用它：

  • 最大选择层级 —— 只能选到第几级。
  • 是否允许非叶子节点 —— 能不能选中间层。
  • 显示格式 —— label（只显示名称）/ code（只显示编码）/ code_label（编码 + 名称）/ full_label（完整路径）。

使用配置可以复用，也可以设一个系统默认。

预览验证

第三个页签输入一个测试值，实时告诉你过不过、不过是卡在哪条约束上，下面还有一份配置概要。配完约束一定在这里试一下，正则写错在这里最容易发现。多级枚举会渲染成树形选择器，按最大选择层级截断可选层。

枚举类型 可同步

资源 → 枚举类型。业务字典库，支持多级层次与从外部数据库同步。四个页签：详情 / 数据 / 同步规则 / 引用。

四种枚举类别

general_single 通用单级 / general_multi 通用多级 / biz_single 业务单级 / biz_multi 业务多级。多级的要设最大层级。

数据页：两种视图

树视图看层次关系，表格视图批量改。两种都支持行内编辑：code、label、父级 code、层级、排序、状态。

层次编码规则

多级枚举的编码怎么拼，在「详情」页签的编码管理里配。每一级填：

  • 码段名、码长、总长
  • 分隔符（级与级之间用什么连）
  • 填充字符 与 填充位置（前补 / 后补）

配的同时下面有示例演算，直接看拼出来长什么样。

从外部库同步

  1. 「同步规则」页签，数据源 → 表 → 字段 三级联动：分别指定编码字段、名称字段、排序字段、状态字段、父级字段。
  2. 需要只取一部分就填过滤 SQL。
  3. 先点测试连接和预览 SQL，确认取到的是想要的数据。
  4. 选同步模式，执行同步。

三种同步模式

模式行为什么时候用
全量覆盖清空后重灌第一次同步，或本地改乱了要重来
逐级对比以业务系统为准，逐级比对增删改常规同步，对方是权威源
增量更新只加新增的，不动已有的本地有人工补充过，不想被冲掉

每次同步落一条日志：新增 / 更新 / 删除 / 失败四个计数 + 错误信息 + 操作人。

同步是手动触发的，没有定时调度。需要定期同步就自己排个时间去点，或者由外部调度调接口。

引用页签

列出哪些对象属性、接口属性用了这个枚举（经值类型的 Enum 约束）。改枚举项之前先看看影响面。

接口 抽象契约

资源 → 接口。类似 OOP 里的 interface：声明「实现我的类必须有这些属性」，本身不落地。四个页签：概览 / 显示 / 属性 / 实现。

属性页签

行内编辑表格：编码 / 名称 / XSD 类型 / 值类型引用 / 必填标记 / 格式化 / 注释。必填标记三态：0 可选 / 1 必填 / 2 多值。

多选几行可以批量设格式化规则，不用一条条点。

实现页签

列出已经实现这个接口的对象类型，可以解绑，也可以点弹框选新的类绑上。重复绑同一个类不会产生第二条记录。

当前只记录绑定关系，不校验对象类型是否真的具备接口声明的全部属性。绑之前自己对一遍，或等一致性校验上线。

状态

启用 / 禁用切换。列表支持批量删除、批量启用、批量禁用，也能按行业分组折叠着看。

类型类 元数据标签

系统配置 → 类型类。给属性 / 关系 / 动作贴的标签，带参数与前端组件映射。上层的图表、图谱靠读这些标签决定怎么渲染。

结构

  • 一级分类（Kind） —— 内置 11 个，左侧彩色圆点列表。分类本身可以增删改（右键菜单）。
  • 类型类定义 —— 挂在某个分类下，分类 + 名称前缀 唯一。
  • 绑定实例 —— 把某个类型类绑到具体载体（属性 / 关系 / 动作）上，并给出参数值。

参数怎么配

简单参数用 param_type × frontend_component 两个字段搭：

param_type可选的前端组件
booleanswitch 开关
enum单选 / 多选下拉
text / numeric文本框 / 数字框
ridRID 选择器
jsonJSON 编辑器

复杂的多字段参数走 JSON Schema（param_json）。抽屉右栏会按 Schema 自动生成表单并实时预览，下面还有原始 JSON 可对照——写 Schema 时左边改右边立刻能看到效果。

几个开关

  • allow_multi_bind —— 同一个载体能不能绑多次。
  • is_array_value —— 参数值是不是数组。
  • system_protected —— 受保护的内置类型类，删不掉也改不了关键字段。

渲染解析

上层要用的时候不是一条条查绑定，而是调 /api/tc-render/resolve，传对象类型或链接，一次拿回它身上所有绑定与参数值。这是图表、图谱真实渲染的地基。

数据源（数据库类）

资源 → 数据源。三个页签：数据源 / 监控 / 物理表。

支持的数据库

12 种：MySQL、PostgreSQL、Oracle、MongoDB、达梦 DM、人大金仓 Kingbase、神通 Oscar、GBase、PolarDB、TDSQL、GaussDB、OceanBase。

选了类型之后系统会从驱动目录带出对应的 JDBC 驱动类名，一般不用手填。MongoDB 走独立的 mongo_url 字段。

建连接

  1. 填基本信息：名称、编码、所属行业、数据库类型。
  2. 填连接配置：JDBC 驱动 / URL / 用户名 / 密码。
  3. 点测试连接。结果会写回连接状态（online 正常 / offline 离线 / risk 风险）和响应时间。
  4. 扩展项：备注、最大连接数、启用状态。
凭证目前是明文存库的，只适合内网可信环境。生产环境落地前需要接密钥托管。

监控页签

2×2 面板：

  • 全局状态 —— 负载条 + 关键指标
  • 基础配置 —— 最小空闲、最大连接
  • 实时状态 —— 活跃连接、等待连接
  • 响应时间

下方两个运维操作：热刷新连接池（配置改了不用重启）、动态调整最大连接数。

物理表页签

点同步，从对端把表和视图的元数据拉进来。拉回来的表可以改显示名、可以删（只删本地元数据记录，不动对端）。表多的时候分页看。

删除数据源会级联销毁连接池并清掉它的物理表记录。已经绑了这些表的对象类型，字段映射会一起失效。

外部数据源 / 接口管理器 HTTP

对方不给数据库、只给一组 HTTP 接口时用这个。它和数据库类数据源在同一个列表页展示，但走独立的表和接口。

建外部数据源

新建时选「接口类」，填基址与鉴权。详情是抽屉（不是整页），三块内容：基本信息 / 调用日志 / 监控。

九种鉴权类型

类型适用场景
无鉴权公开接口、内网免认证服务
API Key开放平台简单认证。要配 Key 名称、参数位置（Header / Query）、密钥值、前缀
Basic AuthHTTP 基础认证，可选自动 Base64 编码
Bearer Token标准 REST 令牌。可配有效期、传递位置、令牌前缀、自动续期及刷新地址
OAuth2.0 客户端模式服务间调用、机器凭证
OAuth2.0 授权码模式用户授权、第三方登录对接
CAS 单点登录企业统一身份认证、内网 SSO
JWT 令牌自包含令牌、微服务内部认证
Digest Auth比 Basic 更安全的 HTTP 摘要认证

表单是表驱动渲染的，字段之间有联动（比如 Bearer 的「自动续期」打开后才出现「刷新令牌地址」）。

接口管理器

数据源行上的入口会在新标签页打开一个类 Postman 的独立工作台。

  • 左：目录树 —— 分组 + 接口两级。接口前的圆点按状态着色（调试 / 完成）。
  • 上：标签栏 —— 可同时开多个接口，有未保存改动的标签带一个圆点。右上角可在新窗口打开。
  • 地址栏 —— 方法下拉（GET 绿 / POST 橙 / PUT 蓝 / DELETE 红）+ 基址（灰色不可改）+ 路径输入 + 发送 / 保存。
  • 请求区 —— 五个页签：设置 / 鉴权 / Header / Query / Body。
  • 响应区 —— 四个页签：实时响应 / 请求头 / 响应头 / 成功响应示例。

请求区与响应区之间、左目录与右侧之间都可以拖拽调整比例。

Body 的五种模式

none / form-data / x-www-form-urlencoded / raw / binary。form-data 的每一行可以是文本或文件（上限 10MB，文件只在内存里、不入库）。

日志与监控

点「发送」是真实发起请求，每次调用都落日志。回数据源抽屉：

  • 日志页签 —— 调用记录列表（筛选栏压成单行）+ 点开看详情。
  • 监控页签 —— 按天的成功率与耗时趋势。
接口级的鉴权配置会覆盖数据源级的。大部分接口用数据源默认那套，个别特殊的在接口的「鉴权」页签单独配。
目前接口只做到「能调通、能看日志」。把接口响应映射成对象类型的属性来源还没做，所以 HTTP 数据源暂时不能像数据库数据源那样直接绑到对象类型上。

字典管理

系统配置 → 字典管理。系统级通用字典——界面上的下拉选项、状态码这类。和「枚举类型」不是一回事，见 概念地图。

  • 左侧字典卡片列表（编码 / 名称 / 状态 / 条目数），带搜索。
  • 右侧条目表，支持平铺和树形两种结构。
  • 改完点右上角 发布重载 刷新全局缓存；也可以在单张卡片上只重载这一个字典。
改了字典条目必须重载缓存才会在界面上生效——字典是缓存在后端内存里的，不重载就还是旧值。

行卡片

图谱

工作区 → 图谱。左右双画布：左边行业层级树（行业 / 领域 / 子领域 / 分组），右边对象本体图。中缝可以拖拽分配宽度，也可以把某一侧折叠起来。

  • 画布上悬浮竖排工具条：适配视图（只缩放居中，不改节点位置）、放大 / 缩小、回到初始布局、单侧全屏。

实例探索 模拟数据

搜索语法

顶部全局搜索框支持四种写法（点搜索框右侧的 ? 随时可以看）：

写法含义
大坝 防渗默认分词，含任一词即命中
"大坝 防渗"引号内为精确短语，必须连续完整包含
黄河 AND 堤防
水库 OR 水闸		逻辑运算，可以加括号：

闸?门 / 灌*通配符：? 单个任意字符，* 任意长度

怎么用

  1. 先用左侧的范围选择（双栏抽屉）按行业 / 领域圈定要看的对象类型，或者直接搜。
  2. 点一个对象类型进探索页。列表视图里配显示列、加筛选、排序、翻页。
  3. 显示列可以跨关联对象取——比如在「水文测站」列表里直接显示它所属河流的名称。前提是两者之间有链接类型。
  4. 切图表视图看分组聚合。不知道用什么图就点图表推荐。
  5. 配好的看板会存到后端（不是浏览器本地），换台机器打开还在。每个对象类型一份默认看板，另外可以存命名设计。
  6. 点某行开详情抽屉，看全部属性和关联对象，顺着关联继续跳到下一个对象。

状态字段的两套口径

不同模块的状态字段类型不一样，看列表时别混：

  • 整数型：1 启用 / 0 禁用 —— 对象类型、接口、数据源、分类等。

常见问题

建完的东西删不掉

大概率是被引用了。系统会告诉你卡在哪：共享属性看「引用」页签，对象类型看「被引用」页签，枚举看「引用」页签。先把引用方改掉或删掉，再回来删。
另一种可能是系统保护——内置的类型类 system_protected=1，设计上就删不掉。

api_name 填错了怎么办

没有改的办法。只能删了重建；如果已经被引用又删不掉，就只能带着这个名字往下走，或者请管理员从数据库层面处理。所以建之前想清楚。

改了字典 / 枚举，界面没变

字典要点发布重载刷缓存。枚举改完如果是通过值类型引用的，检查一下值类型的使用配置（显示格式、最大层级）是不是限制住了。

数据源测试连接失败

按顺序排查：驱动类名对不对（换个类型再换回来让系统重新带一次）→ JDBC URL 格式 → 网络可达性 → 凭证。MongoDB 走的是 mongo_url 而不是 JDBC 那几个字段。

接口管理器点发送没反应

看响应区的「实时响应」页签有没有错误信息。常见原因：基址末尾和路径开头都带了 / 导致双斜杠；鉴权配置没保存（标签上还有脏标记圆点）；请求超时。

实例探索里查不到刚建的对象类型

确认三件事：对象类型是启用状态；它有属性（没有属性的类生成不出实例）；顶部的范围选择器没把它排除在外。

知识浏览器里搜不到刚建的类

Jena 模型不是每次改动都实时重建的。调 POST /api/ontology/rebuild 触发重建，然后回来看状态卡里的类数有没有变。

页面空白 / 改了没生效

浏览器硬刷新 Ctrl + Shift + R。前端有懒加载缓存，路由或组件改动后普通刷新可能拿的还是旧的。

抽屉里的弹框被挡住了

这是 bug，不是设计。大弹框的层级应该高于抽屉（抽屉 1010，大弹框 ≥1200）。碰到了报一下。

常见任务速查

按「我要做什么」组织的操作清单，点开就是步骤。跟左边的说明对着看。

01建一个新的对象类型
  1. 确认落点：系统配置 → 行业分类 里有对应的领域
  2. 资源 → 对象类型，左树选中领域，点新建
  3. 向导填编码 / 显示名 / api_name / 图标 / 颜色
  4. 抽屉「属性」页签逐条加字段
  5. 去实例探索打开它验证能出数
    6. api_name 建完锁死，先想好
02给属性限定取值范围
  1. 取值是固定几项 → 先建枚举类型，把枚举项灌进去
  2. 资源 → 值类型 新建，基础类型选 String，约束选 Enum，绑上刚才的枚举
  3. 配使用配置：最大选择层级 / 允许非叶子 / 显示格式
  4. 「预览验证」页签试一个值
  5. 回对象类型的属性行，值类型选它
    6. 格式约束（手机号、身份证）用 Regex 约束，不用建枚举
03连接两个对象类型
  1. 资源 → 链接 点新建
  2. 上栏填源端：对象类型 + 基数 + 正向显示名
  3. 下栏填目标端：对象类型 + 基数 + 反向显示名
  4. 选落地方式：字段映射，或打开「数据源关系」用中间表
  5. 加映射行，复合主键就加多行
  6. 回对象类型的「链接关系」页签核对图上画的方向
04让一个字段在多个对象上复用
  1. 资源 → 共享属性，走三步向导建一次
  2. 各对象类型的属性里引用它
  3. 要看谁在用：共享属性详情的「引用」页签
    4. 改共享属性不会回写到已引用的对象属性上
05把一组字段打成包
  1. 先把成员字段都建成共享属性
  2. 资源 → 共享属性 → 结构属性 Tab，新建结构
  3. 右侧条目表逐个加共享属性，拖拽排顺序
06从外部库同步一份枚举
  1. 前置：资源 → 数据源 里那个库已连通
  2. 枚举详情 →「同步规则」页签
  3. 三级联动选：数据源 → 表 → 各字段（编码/名称/排序/状态/父级）
  4. 只取一部分就填过滤 SQL
  5. 点测试连接和预览 SQL 确认
  6. 选模式执行：全量覆盖 / 逐级对比 / 增量更新
  7. 看同步日志的四个计数
    8. 手动触发，没有定时调度
07建一个动作
  1. 资源 → 动作类型，五步向导定主体对象
  2. 详情工作台「表单」页：建分区 → 加参数 → 逐个配值/显示
  3. 「规则」页：按执行顺序加规则卡片，拖拽排序
  4. 每条规则配属性映射：目标属性 ← 值来源
  5. 「安全与提交」页配提交条件树
  6. 管理页点 ▶ 试运行，确认执行计划
  7. 状态从「草稿」改「已发布」
    8. 试运行不写物理表
08动作参数的选项从对象来
  1. 参数详情 →「值」标签
  2. 数据类型选 object（对象引用）或字符串多选
  3. 配「从对象集获取」：起始对象集 → 按属性过滤 → 关联搜索
  4. 字符串多选还要选返回属性（取对象的哪个字段当值）
    5. 起始对象集可以引用表单里已有的对象参数当变量
09接一个数据库
  1. 资源 → 数据源 新建，选 12 种类型之一
  2. 驱动类名一般自动带出，填 URL / 账号 / 密码
  3. 点测试连接，看状态变 online
  4. 「物理表」页签点同步，拉表结构
  5. 回对象类型「数据源」页签绑表，再逐个属性映射列
    6. 解绑数据源会清空该绑定下所有字段映射
10接一组 HTTP 接口
  1. 新建外部数据源，填基址
  2. 选鉴权类型（9 种），按表单填字段
  3. 打开接口管理器（新标签页）
  4. 左侧建分组和接口
  5. 地址栏选方法填路径，配 Header / Query / Body
  6. 点发送真实调用，看响应区
  7. 回数据源抽屉看「日志」和「监控」
    8. 接口级鉴权会覆盖数据源级
11声明一个契约（接口）
  1. 资源 → 接口 新建
  2. 「属性」页签加属性，设必填标记（可选/必填/多值）
  3. 多选几行可以批量设格式化
  4. 「实现」页签绑上要实现它的对象类型
    5. 当前不校验对象类型是否真的有这些属性，自己对一遍
12给属性/关系贴元数据标签
  1. 系统配置 → 类型类，左侧选或新建一个分类
  2. 新建类型类，填名称前缀 + 适用类型
  3. 配参数：简单的用 param_type + 前端组件；复杂的写 JSON Schema
  4. 右栏看自动生成的表单预览
  5. 去对象类型 / 链接的「类型类」页签绑定并填参数值
13查一批数据看看
  1. 工作区 → 实例探索
  2. 范围选择器圈定领域，或直接搜（支持 AND/OR/引号/通配符）
  3. 点对象类型进列表，配显示列（可跨关联对象取）
  4. 加筛选 + 排序 + 翻页
  5. 切图表视图，或用图表推荐
  6. 配置自动存成该对象类型的默认看板
    7. 数据是模拟生成的，别当业务数据看
14确认改动进了语义层
  1. 辅助工具 → 知识浏览器
  2. 看三张状态卡是否就绪
  3. Jena「类」子页搜刚建的类
  4. 搜不到就调 POST /api/ontology/rebuild
  5. 向量库页签用自然语言检索验证召回
15删不掉的东西怎么处理
  1. 看报错里的引用清单
  2. 共享属性 → 「引用」页签找引用方
  3. 对象类型 → 「被引用」页签
  4. 枚举 → 「引用」页签
  5. 把引用方改掉或删掉，再回来删
    6. system_protected=1 的类型类设计上就删不掉
16新建一个领域和命名空间
  1. 系统配置 → 行业分类
  2. 选中行业节点，快速添加菜单选「领域」
  3. 填编码（小写下划线）/ 中文名 / 图标 / 颜色
  4. 抽屉「命名空间」页签绑 ns_code / URI / 版本
  5. 需要按主题再分就在领域下建分组，并把对象类型加为成员
